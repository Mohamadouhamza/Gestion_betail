# Gestion Bétail - Flutter App COMPLÈTE

Application mobile complète de gestion du cheptel - 5 écrans + toutes les fonctionnalités.

## 🎯 Fonctionnalités COMPLÈTES

✅ **5 Écrans Complets:**
- Home : Situation en temps réel + derniers mouvements
- Mouvements : Enregistrer achats, ventes, pertes, naissances
- Inventaire : Gérer les lots par catégorie + filtres d'âge
- Historique : Voir tous les mouvements + supprimer (swipe)
- Fiche Papier : Tableau récapitulatif complet

✅ **Fonctionnalités:**
- Gestion de propriétaires multiples
- Gestion de troupeaux multiples
- Suivi gestation des vaches
- Filtres par âge pour taurions
- Calcul automatique de l'âge
- Situation en temps réel (T, G, V, VM, VF)
- Base de données SQLite locale (hors ligne)
- Dark-friendly UI Material 3

## 🚀 Build avec GitHub Actions

### 5 minutes rapides:

1. Crée compte GitHub → https://github.com/signup

2. Crée repo PUBLIC "gestion-betail"

3. Clone et push:
```bash
git clone https://github.com/TON_USERNAME/gestion-betail.git
cd gestion-betail
# Copie fichiers du ZIP ici
git add .
git commit -m "Initial commit"
git push
```

4. Attends ~15 min → Actions → Télécharge app-release.apk

5. Installe:
```bash
adb install -r app-release.apk
```
